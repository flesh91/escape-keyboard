# Escape Keyboard

[English](README.md)

Повноцінна клавіатура як на ПК для Android: Esc, Ctrl, Alt, Tab, Fn, стрілки,
Home/End/Del і F1–F12, зі справжніми комбінаціями клавіш. Для SSH-клієнтів,
терміналів, віддаленого робочого столу і всіх, кому бракує звичної розкладки
на телефоні.

Escape Keyboard — перероблений форк [Hacker's Keyboard](https://github.com/klausw/hackerskeyboard)
(Klaus Weidner) зі змінами Maxim Pulya, оновлений під Android 17.

**[Завантажити останній APK](../../releases/latest)**

- Пакет: `app.escapekeyboard`
- Android 5.0 і новіше, розрахована на Android 17 (API 37)
- Дозволи: лише вібрація і словник користувача. Доступу до інтернету немає,
  тож набране нікуди не передається.

## Можливості

**Розкладки й мови**
- Компактна (5 рядів), повна (5 рядів) і 4-рядна розкладки.
- Українська й російська ЙЦУКЕН у компактній розкладці. Компактна форма є
  приблизно для 30 мов, загалом мов понад 40.
- Одну додаткову клавішу можна зробити емодзі, буфером обміну, глобусом (наступна мова) або
  мікрофоном: Tab ліворуч від пробілу в компактній розкладці, шестерню в інших (налаштування
  лишаються на довгому натисканні).

**Термінал**
- Свій ряд клавіш із макросами над клавіатурою. За замовчуванням вимкнений.
- Ctrl і Alt працюють як справжні модифікатори й підсвічуються, коли ввімкнені.
- Виділення як на ПК: натисніть Shift, а потім стрілки, Home/End чи PgUp/PgDn або проведіть
  по пробілу в режимі курсора. З Ctrl виділяються цілі слова. Ctrl+A виділяє все.

**Набір тексту**
- Вбудовані словники для української, російської та англійської: підказки й
  автовиправлення.
- Історія буфера обміну в плаваючому вікні: закріплення, редагування,
  видалення свайпом із можливістю повернути запис. Відкривається й довгим натисканням Enter,
  після вставки закривається саме.
- Панель емодзі й голосове введення через встановлену голосову клавіатуру.
- Підказки автозаповнення від менеджера паролів (Android 11+).

**Жести**
- Свайп по пробілу на вибір: перемикає мову або рухає курсор. У режимі курсора мову
  перемикає додаткова клавіша з глобусом.
- Режим для однієї руки: клавіші притискаються до лівого або правого краю,
  ширина від 60 до 95 %. Режим можна вмикати свайпом ліворуч або праворуч.

**Теми**
- Google: за темою системи, світла, темна, кольори шпалер (Material You).
- Cupertino і Keycap (світлі або темні за темою системи), Graphite і класичні теми
  Hacker's Keyboard.

**Налаштування**
- Налаштування в стилі Material 3, повний переклад українською та російською.

## Встановлення

1. Завантажте `EscapeKeyboard-*.apk` з [Releases](../../releases) і встановіть.
2. Відкрийте Escape Keyboard і виконайте два кроки на стартовому екрані:
   увімкніть клавіатуру в системних налаштуваннях введення і зробіть її активною.

Escape Keyboard встановлюється окремим застосунком поряд із Hacker's Keyboard.
Налаштування з неї не переносяться.

## Свій ряд клавіш і макроси

Налаштування → Термінал і клавіші ПК → Свій ряд клавіш. Клавіші пишуться через пробіл:

| Що | Приклад |
|---|---|
| Назви клавіш | `Esc Tab Enter Bksp Del Ins Home End PgUp PgDn Up Down Left Right F1`…`F12` |
| Модифікатори | `Ctrl Alt` — вмикаються й вимикаються, як на клавіатурі |
| Комбінації | `Ctrl+C Alt+F Ctrl+Left` |
| Будь-який окремий символ | `\| ~ / -` |
| Текст у лапках вводиться як є | `"sudo "` `"\| grep "` `"\n"` — новий рядок |

За замовчуванням ряд такий: `Esc Tab Ctrl Alt | ~ / - "sudo " "| grep "`.

- Стрілки й ⌫ повторюються, поки клавішу тримають.
- Довгий ряд прокручується, і прокручування нічого не вводить.

## Збирання

Потрібні JDK 21, Android SDK (platform 37, build-tools 37.0.0),
NDK 29.0.14206865, CMake 4.1.2.

```bash
./gradlew assembleRelease   # APK для встановлення вручну
./gradlew bundleRelease     # AAB для Google Play
```

Релізні збірки підписуються ключем із `keystore.properties`. Файл лежить поряд
із `settings.gradle` і ніколи не комітиться:

```properties
storeFile=escape-keyboard-upload.jks
storePassword=...
keyAlias=upload
keyPassword=...
```

Без цього файлу релізна збірка підписується локальним debug-ключем. Така збірка
підходить для встановлення вручну, але не оновить офіційну, і Google Play її
не прийме.

Вбудовані словники генерує [tools/dict](tools/dict/README.md).
