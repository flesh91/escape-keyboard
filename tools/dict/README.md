# Вбудовані словники

Генерує основні словники для підказок і автовиправлення:
`app/src/main/res/raw-uk/main.dict`, `raw-ru/main.dict`, `raw-en/main.dict`.
Для інших мов лишається заглушка `raw/main.dict`, тож підказок там немає.

## Звідки слова

Частоти слів беруться з [wordfreq](https://github.com/rspeer/wordfreq) 3.1.1, список `large`.
wordfreq зводить Вікіпедію, субтитри OpenSubtitles, SUBTLEX, Google Books Ngrams, ParaCrawl
і Twitter. Дані поширюються під **CC BY-SA 4.0**: авторство й умови вказані в `NOTICE`,
його показує екран «Ліцензії відкритого коду». Самі словники теж під CC BY-SA 4.0.
Комерційне використання дозволене.

## Що робить `build_dicts.py`

- бере 300 тис. найчастіших слів для `uk` і `ru` і 250 тис. для `en`; після фільтрів лишається
  близько 259 тис., 275 тис. і 197 тис. (словник має вміститися в 4 МБ, див. нижче);
- рідкісні слова (далі перших 160 тис. для `uk`/`ru` і 110 тис. для `en`) відкидає, якщо вони
  схожі на одруківку набагато (у 100+ разів) частішого слова: відрізняються однією літерою
  або мають ті самі літери в іншому порядку («сьогдні», «сегодя», «пожайлуста»);
- лишає лише слова з літер своєї мови, відкидає «розтягнуті» слова на зразок «бляяяя»;
- слова, які значно частіше трапляються в іншій мові (російські «что», «как» в українському
  списку), лишає правильними, але не пропонує (частота 0);
- так само позначає лайку: слово не виправляється, але й не пропонується;
- прибирає написання без апострофа, якщо є форма з апострофом: «мясо» → «м'ясо»,
  «dont» → «don't» (крім справжніх слів: its, well, were…);
- злиті написання слів із дефісом перетворює: «чтото» → «что-то»; поширені слова з дефісом
  («що-небудь», «будь-який», «по-українськи») додає окремим списком.

Рушій клавіатури пропускає апостроф і дефіс, яких не набрали: «щонебудь» знайде «що-небудь».

## Як перезібрати

```bash
python3 -m venv /tmp/wf && /tmp/wf/bin/pip install wordfreq==3.1.1
/tmp/wf/bin/python tools/dict/build_dicts.py app/src/main/res
```

## Як перевірити без телефона

`dicttest.cpp` збирає справжній рушій клавіатури (`app/src/main/cpp/dictionary.cpp`) для Mac
і показує, що він запропонує на набране слово. Сусідніх клавіш перевірка не враховує.

```bash
xcrun clang++ -O2 -w -isysroot "$(xcrun --show-sdk-path)" -I app/src/main/cpp tools/dict/dicttest.cpp app/src/main/cpp/dictionary.cpp app/src/main/cpp/char_utils.cpp -o /tmp/dicttest
```

```bash
/tmp/dicttest app/src/main/res/raw-uk/main.dict мясо сьогдні щонебудь
```

## Обмеження формату

Формат старий, з Android 2.3: частота займає 1 байт, адреси мають 22 біти, тож словник
має бути меншим за 4 МБ. Пари слів зі словника рушій читає лише для латиниці, тому їх не
записуємо.
